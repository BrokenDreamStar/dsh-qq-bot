# SOUL.md 模板

- `blue-fat-fish.md` — 「蓝色大肥鱼 / DeepSeek 小鲸鱼」QQ 群友版人格。纯正文，可直接作为某个会话的 `SOUL.md`，或粘贴到 WebUI「人格模板」新增模板。

## 用法

1. WebUI → 设置 → dsh-qq-bot → 「人格模板」→ 新增「蓝色大肥鱼」→ 粘贴 `blue-fat-fish.md` 全文；
2. 「会话人格」→ 选择会话 → 套用该模板；也可以直接把文件内容写到该会话目录的 `SOUL.md`；
3. 保存后当前会话会重建，下一条消息生效。
